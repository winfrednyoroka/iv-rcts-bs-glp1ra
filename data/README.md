# Data directory

## Overview
This directory contains data used in this project:
> Instrumental Variable Analysis applied on Randomised Controlled Trials of Glucagon-like-peptide-1 Receptor Agonists and Bariatric Surgery.

The project consists of two sources of evidence:
1. Bariatric Surgery (BS)
2. Glucagon-like-peptide-1 receptor Agonists (GLP1RAs)

The data is not tracked in Git and are not included in this repository.

## BS
Contains the bariatric surgery summary trial data.     

raw/     Original dataset etxracted from papers      
processed/     Analysis-ready datasets         


## GLP1RAs        

Contains GLP1RAs summary trial data.   

raw/     Original dataset etxracted from papers     
processed/     Analysis-ready datasets      



## Data availability
At the time of submitting a manuscript related to this project. The data will be shared via zenodo.

This repository provides the code and project structure required to reproduce analyses once access to the underlying datasets has been obtained.
